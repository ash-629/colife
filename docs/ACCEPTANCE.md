## 自动化范围

- 领域：真实日期、容量、固定安排、目标预算回滚、依赖循环与完成顺序、完成任务保护。
- 事务：非法提案整体回滚、同一提案幂等、失效检测、复习任务幂等与重生成。
- API：健康、手动生命周期、统一状态、非法字段与未知 Origin 拒绝。
- 模型与编排：未配置、401 不重试且脱敏、429 有限重试、结构化上游交接、失败缓存、取消、重启恢复、校验反馈修正。
- 反馈与存储：提交前答案隔离（测验与运行日志）、计分幂等、专注统计、日期趋势、持久化、在线备份与完整性。
- UI 语义：有名称的依赖多选、错误提示与用户文本转义。

自动化模型调用使用可控替身验证异常分支；浏览器正常主流程使用真实 DeepSeek，不以替身结果冒充真实运行。

## 已知边界

本机单人版本，未提供公网多用户认证、具体时段拖拽、自动通知、跨设备同步和第三方日历。资料链接由用户录入，未自动检索验证外部内容。学习路线为阶段建议，最终执行日期以确认任务为准。模型分析可能存在推测或说明偏差，确定性校验保证任务容量、依赖和截止日期，用户确认后才执行。

node:sqlite 在当前 Node 版本输出实验特性提示。已验证 SQLite 持久化、迁移、事务和备份恢复；未验证其他浏览器或公网部署。首版无阻断问题，已知范围均明确记录。
