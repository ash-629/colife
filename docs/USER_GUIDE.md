# 同频 CoLife 体验指南

同频 CoLife 帮你把学习与生活目标变成可执行的计划，再通过任务、测验、习惯和复盘持续调整。

跟着下面的步骤，可以体验「创建目标 → Agent 规划 → 执行记录 → 学习反馈 → 复盘调整」的完整流程。建议预留20分钟，生成计划时稍等片刻。

## 开始体验

打开分享者提供的体验地址，使用分享者提供的账号和密码登录。

当前是共享体验空间。创建目标、任务和习惯时，可以在名称前加上自己的昵称，方便辨认；优先操作自己创建的记录。

如果只想快速看看，可以先打开「目标空间」中已有的「React 学习与项目实践」，查看任务、学习路线和协作记录，再选择下面感兴趣的功能体验。

## 1. 创建一个想完成的目标

**入口：** 左侧「目标空间」→「＋ 新建目标」。

可以使用下面的示例，也可以换成自己的学习主题：

| 字段 | 填写示例 |
| --- | --- |
| 目标名称 | 小林：掌握 React Hooks 并完成小练习 |
| 类型 | 学习 |
| 截止日期 | 今天起14天后 |
| 每日可用分钟 | 30 |
| 验收标准 | 完成计数器练习，能解释 useState 和 useEffect 的用途 |
| 背景与时间限制 | 已了解 JavaScript，每晚可学习30分钟，希望从基础开始，每次任务尽量小一些 |

点击「保存」，再点击新目标的名称打开详情。

**你会看到：** 目标以「草稿」状态保存，详情中包含截止日期、时间预算和验收标准。

## 2. 让 Agent 一起制定计划

**入口：** 目标详情 →「生成学习生活计划」。

1. 点击生成按钮，观察各个 Agent 的状态和摘要。
2. 等待状态变成「待确认」，点击「审阅提案」。
3. 阅读建议的任务、日期、时长和优先级。
4. 觉得合适，点击「确认并应用」。

**你会看到：** 新任务进入日程，目标变成「进行中」。计划确认前，任务不会加入执行列表。

不打算采用这份建议，可以点击「保留原计划」。关闭弹窗后，运行仍会继续；要停止生成，点击「取消运行」。

## 3. 看看接下来要做什么

**入口：** 左侧「任务与日程」。

1. 用「筛选目标」选中自己的目标。
2. 在「任务看板」中查看待办、进行中和已完成任务。
3. 切换「周日历」，用「上一周／下一周」查看任务安排。
4. 点击任务，查看备注和前置任务。

**你会看到：** 看板与日历对应同一份安排。手机或窄屏中，日历可以左右滚动。

想额外记录一件事，点击「＋ 添加任务」，填写名称、关联目标、日期和预计分钟。比如「小林：整理学习笔记」，预计10分钟。若当天时间已满，换一个有空余时间的日期。

有前置依赖的任务，需要先完成前置任务，才能开始或完成后续任务。

## 4. 体验专注与任务完成

**入口：** 点击一条没有未完成前置任务的任务 →「开始专注」。

1. 让计时运行约1分钟，点击「暂停」。
2. 关闭弹窗，再点击顶部「◷ 继续专注」，查看保留的时间。
3. 点击「继续」，最后点击「结束并记录」。
4. 完成任务后，在任务详情点击「标记完成」。

**你会看到：** 专注时间被记录，任务进入已完成列，目标的任务进度随之增加。

专注结束和任务完成分别记录。计时不足1分钟时，统计可能显示0分钟。安排在今天的任务完成后，「今日工作台」也会更新。

## 5. 留下资料和自己的理解

**入口：** 左侧「学习中心」→选择自己的学习目标。

1. 查看「当前学习路线」和「关联执行任务」。
2. 点击「＋ 添加资料」，填写资料标题、网址与说明，保存。
3. 点击「＋ 写一条笔记」，写下自己的理解，保存。
4. 找到笔记，点击「编辑」补充内容。

笔记可以这样写：

- 标题：我对状态的理解
- 正文：useState 保存组件状态，更新状态后页面会重新显示；我想用计数器练习它。

**你会看到：** 资料和笔记保存在所选目标下，刷新页面后仍然保留。

阶段路线提供学习方向，具体执行日期以「任务与日程」中的安排为准。

## 6. 做一次测验，看看哪里需要复习

**入口：** 「学习中心」→「✧ 生成知识测验」。

1. 等待生成完成，点击「开始测验」。
2. 为每道题选择答案，点击「提交并查看反馈」。
3. 阅读得分、正确答案和逐题解析。
4. 有错题时，点击「生成复习提案」。
5. 查看复习主题与日期，点击「确认并应用」。

**你会看到：** 成绩和薄弱点保存在「知识反馈」中，确认后出现一条关联目标的复习任务。

全部答对时无需生成薄弱点复习。想再测一次，可以重新点击「生成知识测验」。复习任务会安排到有空余时间的日期，不一定是明天。

## 7. 给生活做一个小记录

**入口：** 左侧「习惯与生活」。

1. 点击「＋ 添加习惯」，名称填写「小林：每日阅读」，每日目标填写「阅读20分钟」，保存。
2. 点击「完成今天的打卡」，观察达成率与连续天数。
3. 点击「✓ 已打卡 · 撤销」，再打卡一次，体验记录的变化。
4. 在「今日精力记录」中选择符合当前状态的一项。

**你会看到：** 同一天重复打卡不会累加次数，撤销后统计会更新。记录精力本身不会改变任务安排。

当前精力记录由体验者共享，选择后也会影响其他访客后续生成的建议。

## 8. 审阅一次排期调整

**入口：** 「任务与日程」→「✧ 重新排期」，或「习惯与生活」→「查看调整建议 →」。

1. 等待生成完成，点击「审阅提案」。
2. 阅读任务的日期变化和调整理由。
3. 合适就「确认并应用」，否则「保留原计划」。
4. 回到周日历查看结果。

**你会看到：** 任务只有在确认后才移动，已完成任务保持原位。当前安排合适时，提案也可能显示「当前无需调整执行任务」。

这项功能会综合整个共享空间的日程；确认前请查看它涉及哪些任务。

## 9. 回头看一次，再决定下一步

**入口：** 左侧「复盘与洞察」。

1. 在「今日复盘」和「本周洞察」之间切换，查看完成、专注与打卡记录。
2. 点击「✧ 生成复盘」，等待协作完成。
3. 关闭运行弹窗，在「复盘记录」中阅读事实、原因分析与建议。
4. 点击「查看调整提案 →」，决定是否采用建议。

**你会看到：** 复盘基于已经保存的记录，建议可以进入下一轮安排，也可能无需改动任务。

「实际完成」按完成当天统计，「计划完成率」按原定安排日期统计；专注时长来自结束后的计时记录。刚开始体验时，记录较少或部分指标为0都是正常的。

## 还可以试试

- **搜索：** 在顶部输入目标或任务名称的一部分，点击结果进入详情。
- **回看协作：** 在「Agent 协作」中找到运行记录，点击「查看」，回看各角色的产出摘要。
- **目标验收：** 关联任务全部完成、且达到自己填写的标准后，在目标详情点击「确认目标验收」。任务进度100%与目标验收分别处理。

## 遇到提示时怎么办

| 提示或情况 | 可以这样处理 |
| --- | --- |
| 当天时间超量 | 换一个有空余时间的日期，或缩短新增任务时长 |
| 前置任务未完成 | 先完成它，再操作后续任务 |
| 提案已失效 | 点击「重新生成提案」，获得基于最新记录的建议 |
| 运行失败 | 阅读原因，点击「重试失败节点」；持续失败时联系分享者 |
| 已有协作正在运行 | 等待当前协作结束后，再发起新的协作 |
| 页面无法打开 | 联系分享者确认体验入口是否仍在运行 |

体验结束后，可以把最顺畅的一步、最困惑的一步，以及希望增加的功能反馈给分享者。
