## 执行路径

- 制定计划、调整日程：协调分派 → 学习与生活并行分析 → 计划整合 → 复盘检查。
- 执行复盘：协调分派 → 学习与生活并行分析 → 复盘分析 → 计划整合。
- 生成测验：协调分派 → 学习生成测验。

同阶段角色读取相同上游结果，不读取同阶段兄弟节点的产出。后续阶段等待当前阶段全部成功或跳过后启动。暂停的可选角色跳过，必要角色暂停时阻止发起。

## 恢复与验证

并行分支分别记录状态，每次完成均读取最新运行记录后写入，避免覆盖另一分支。一个分支失败不会启动下游；已成功的分支在重试时复用。所有分支收尾后才释放运行控制器。取消会中止模型请求，迟到结果不会生成提案。最终排期校验失败时，重新执行计划节点及依赖它的后续阶段。

回归测试使用可控的异步门闩验证两个模型请求同时处于运行中，检查上游隔离、汇合等待、单分支与双分支失败重试、并行取消及既有校验路径。无新增字段输入要求、无架构变更、无待确认项。
