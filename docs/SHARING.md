# ngrok 临时体验入口

应用继续监听本机 4010，由 ngrok 转发 HTTPS 请求。入口使用 ngrok Traffic Policy 的 Basic Auth 临时密码保护；访问者共享同一个个人空间，并使用本机服务端的模型配置。

## 体验入口

使用启动ngrok后生成的临时HTTPS地址，由部署者单独提供给体验者。文档不保存每次变化的公网地址。

部署者在本机准备`data/ngrok-traffic-policy.json`，配置ngrok Basic Auth，并单独提供体验账号和密码。策略文件已忽略提交，不将访问密码写入文档或源码；公开仓库不包含此本机文件。

## 重新启动

在工程目录运行 `npm start` 保持应用启动，再在另一个终端运行：

```powershell
ngrok http http://127.0.0.1:4010 --traffic-policy-file data/ngrok-traffic-policy.json --inspect=false --log=stdout
```

如果 ngrok 分配了新地址，将 `.env` 的 `PUBLIC_ORIGINS` 更新为该 HTTPS 地址并重启应用。来源按确切地址放行，不允许任意 ngrok 域名。已有 DeepSeek 配置保持不变。

停止当前 ngrok 命令即可关闭隧道；本机应用停止或电脑休眠后，外部访问也会不可用。

## 已验证

- 无密码访问健康接口：401。
- 使用体验账号访问首页：200，页面标题正常。
- 使用体验账号访问健康接口：200。
- 公网来源的无效任务请求：400，已通过来源检查并进入字段校验；未写入业务记录。
- 未知来源的写请求：403。
- 类型检查及3项接口测试通过，包括确切来源放行与其他域名拒绝。

这是共享体验入口，不是独立用户或多租户部署。访客操作会改变共享体验记录，真实模型请求会使用当前账号额度。
