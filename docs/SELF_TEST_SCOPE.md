# 全功能自测输入与范围

日期：2026-10-08。正式数据保持独立，自动化使用内存数据库，真实模型与浏览器使用 data/self-test.sqlite（端口4011）。

## 输入分析

七个入口：今日总览、目标、任务、学习、生活、Agent、复盘；设置、搜索及详情弹窗属于跨页面功能。

接口按 health/state/search/settings/goals/tasks/habits/checkin/energy/notes/resources/focus/runs/proposals/quizzes/stats 分组，共17组。写入必须通过字段校验及来源校验；未知资源404，业务冲突409，字段错误400，服务错误隐藏内部信息。

目标标题1–60字、每日15–480分钟、截止日期有效且创建时不早于今天；任务标题1–80字、1–480分钟、依赖最多30项；习惯名称1–30字、目标1–60字；笔记标题1–60字、正文1–2000字；资源只支持HTTP(S)；设置每日15–960分钟、最多100条固定安排、有效IANA时区。空格、上下边界、越界、非法日期、未知字段、错误数据类型均纳入自动化。

状态链：目标草稿→规划中→待确认→进行中→已完成/归档；任务待办→进行中→完成，并允许恢复；运行排队→运行→待确认/成功/失败/取消，失败可重试；提案待确认→应用/拒绝，过期不可应用；专注运行→暂停→恢复→结束；测验未提交→结果→复习提案。

关键规则：每天总容量与目标容量、截止日期、依赖完成顺序和无环、已完成任务保护、提案原子应用与版本检查、重复应用幂等、成功Agent节点重用、取消后不落地、测验答案隔离及评分幂等、统计使用实际完成时间、持久化和备份恢复。

## 验证方式

1. 自动化：所有接口、输入边界、权限来源、状态流转、故障、事务及数据隔离。
2. 独立HTTP服务：真实DeepSeek规划、测验、重排、复盘与数据保存。
3. 浏览器：七页导航、表单、搜索、详情、反馈、专注、Agent/提案和移动宽度。
4. 工程：类型、格式、构建、依赖、实际响应性能；已实现脚本的备份恢复。

无需验证的能力：多账号角色、批量导入导出、分页、上传、通知（当前产品无这些功能）。浏览器内核仅当前Chromium；不把未执行的跨浏览器、真实触屏和长期压力测试计为通过。
