| BUG-04 / P2 | 目标/任务PATCH传status为空字符串、null、false或0，原先返回200并静默保留旧状态 | 仅未提供status时使用旧值；明确传入非法状态返回400，两类接口全部回归通过 |

同时补齐通用下拉表单的required属性，使浏览器必填校验与字段定义一致。

## 浏览器与真实DeepSeek流程

1. **今日工作台**：空态指标均为0；新建目标后显示1个目标；任务、打卡与精力跨页同步。
2. **目标空间**：新建目标表单保存、状态筛选、详情进度正确；关联任务未完成时点击验收，详情内显示“请先完成关联任务再验收目标”。
3. **真实规划**：目标为React状态管理学习；五个Agent均成功，共生成三个20分钟任务，日期为10月8/9/10日。审阅前任务为0，确认后看板出现3项，学习路线出现三阶段。
4. **任务与日程**：看板、周日历、上一周/下一周、状态筛选通过；依赖未完成时切换进行中出现错误，状态仍为待办。手动创建15分钟高优先级任务，再编辑名称和备注，回填及保存正确。
5. **专注**：开始显示25分钟倒计时；暂停后跨页，顶部出现继续入口；恢复和结束成功。实际短会话不足一分钟，统计按分钟显示0，未伪造25分钟记录。
6. **学习资料/笔记**：保存React官方资料与状态快照笔记；链接渲染正确，HTML测试字符串以原文显示。
7. **真实测验**：DeepSeek生成4道题；未答题提交被浏览器必填校验拦截；提交后3/4分，展示选项、正确答案、解析和薄弱点。
8. **复习提案**：基于错题生成25分钟复习任务，审阅后应用，任务总数从3变4。
9. **习惯与生活**：创建每天阅读10页；打卡后100%、连续1天；撤销后0%，再次打卡恢复。习惯编辑回填正确。
10. **真实重排**：记录疲惫后任务日期不自动变化；重排生成提案，确认后复习改到10月10日、useEffect改到10月11日；任务ID和数量保留，无重复新增。
11. **真实复盘**：完成第一项后今日1/1、100%；周统计1/4、25%、85分钟计划、1次打卡。五个节点均成功，复盘记录保存生成时事实。审阅提案后选择保留原计划，运行成为rejected，任务不改变。
12. **事实快照**：之后新增手动任务，实时统计随记录变化，历史复盘的生成时事实保持原值，这不是统计冲突。
13. **设置**：将总容量改成15分钟，弹窗显示容量冲突；数据回滚；修正为120后可保存。
14. **搜索**：输入React显示目标结果；空词清空；后端目标和任务搜索分别有断言。
15. **草稿回归**：额外3题是明确的UI测试夹具，非DeepSeek产出。选择第一题、关闭重开仍选中；补答提交得2/3分。
16. **持久化**：浏览器刷新与QA服务重启后，目标、任务、测验结果、习惯、资料、笔记及结束的专注均保留。
17. **布局**：桌面1280px及390px窄屏均实测；七页无横向溢出。浏览器捕获的error/warn日志为空。

原生confirm弹窗在当前浏览器自动化接口中会导致单次操作超时；后续页面已验证实际结果。关闭后答案保留已经直接验证，尚未分别自动验证原生提醒的“留在页面”和“离开页面”两种选择。
